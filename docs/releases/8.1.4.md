# Copilot Bridge Atlas 8.1.4

## Codex context budgeting

- Reserve the advertised maximum output tokens when calculating a Copilot model's input budget. Honor a lower advertised prompt limit and retain the provider's total context window in catalog metadata.
- For Copilot models that report 1,050,000 total tokens and 128,000 output tokens, Atlas now advertises an input window of 922,000 tokens before Codex's own safety margin.
- Refresh the Atlas model catalog and start a fresh Codex chat to pick up the revised budget.
