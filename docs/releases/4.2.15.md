# Copilot Bridge Atlas 4.2.15

This release removes the duplicate inline filter toolbar from the Request Logs tab on the Usage dashboard.

## Request Logs Tab Streamlining

- Removes the duplicate status-code and date-range filter toolbar above the request logs table in the Usage tab.
- Request logs now rely directly on the global model selector, date range picker, and auto-refresh controls in the Usage dashboard header, ensuring consistent filtering across the summary hero, trend charts, and table.
- Cleans up unused component state and keeps test coverage aligned with the streamlined interface.

## Upgrade Notes

- Install `Copilot-Bridge-Atlas-4.2.15-Windows-x64.msi`. The matching `.sha256` file is included for download verification.
- Existing settings, accounts, pricing configuration, and logged requests are preserved.
