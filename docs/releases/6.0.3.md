# Copilot Bridge Atlas 6.0.3

Refreshing models now removes models that Copilot no longer makes available from
Settings and the generated Codex model catalog. Removed models' preferences are
discarded; if a model returns later, it is imported as new.

- Apply the same removal during startup capability refresh.
- Keep enable switches for models that are still available.
- Clear the saved and generated catalogs when a successful refresh returns no
  compatible models. A failed refresh keeps the existing catalog.

Install `Copilot-Bridge-Atlas-6.0.3-Windows-x64.msi` and verify it with the matching
`.sha256` file. Existing Atlas 6 accounts, usage history, and pricing are preserved.
