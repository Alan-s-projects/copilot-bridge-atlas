# Copilot Bridge Atlas 5.0.8

Atlas now writes one concise Info entry per completed upstream HTTP request.
It includes an Atlas diagnostic ID, status, duration, safe endpoint and model
identifiers, transport, streaming and applied reasoning metadata, outgoing byte
and request-shape counts, response size, truncation, and allowlisted upstream
correlation IDs. Failures also receive a bounded Warn summary of a recognized
JSON error or plain-text response. The Atlas ID links that entry to the failed
request in Usage history, including later body-read and stream failures.

Diagnostic logging is always enabled with a fixed Info ceiling. Settings no
longer shows the log switch or level picker. Old saved log settings remain
untouched but have no effect. The logs omit credentials, prompts, tool output,
arbitrary headers and full request bodies. When an upstream sends only
“Bad Request,” Atlas cannot determine the rejected field.

There is no database migration. Existing accounts, pricing, model choices,
backups and history are preserved. Install
`Copilot-Bridge-Atlas-5.0.8-Windows-x64.msi` and use its `.sha256` file to
verify the download. The per-user Windows installer is unsigned and is not
installed automatically by publishing this release.
