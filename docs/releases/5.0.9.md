# Copilot Bridge Atlas 5.0.9

When Grok uses Copilot's Responses transport, Atlas now preserves a Codex
`agent_message` whose content can be represented as ordinary message text or
an image. Content that cannot be represented is rejected before the request
is forwarded, rather than being sent as an unsupported item type or silently
dropped.

This change is limited to `agent_message` compatibility. It has not been
verified against a live Grok request, and it does not establish the cause of
an upstream response that contains only “Bad Request.”

There is no database migration. Existing accounts, pricing, model choices,
backups and history are preserved. Install
`Copilot-Bridge-Atlas-5.0.9-Windows-x64.msi` and use its `.sha256` file to
verify the download. The per-user Windows installer is unsigned and is not
installed automatically by publishing this release.
