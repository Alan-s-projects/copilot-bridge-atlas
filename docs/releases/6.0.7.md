# Copilot Bridge Atlas 6.0.7

macOS Intel support returns alongside the Windows x64 installer. Download the
package for your computer:

- Windows: `Copilot-Bridge-Atlas-6.0.7-Windows-x64.msi`
- Intel Mac, macOS 13 or newer: `Copilot-Bridge-Atlas-6.0.7-macOS-Intel.dmg`

Each package includes a matching `.sha256` file. On macOS, open the DMG and drag
**Copilot Bridge Atlas.app** into **Applications**. The Mac app is ad-hoc signed
and is not Apple notarized; first launch may require approval in
**System Settings → Privacy & Security**.

This release restores Mac single-instance startup, reopening from the Dock,
and launch-at-login registration. It also fixes atomic file replacement on
macOS so Atlas's saved settings, authentication, and generated model catalog
persist correctly. The app uses the existing icon and interface; the About
update notice names the package for the current platform.

The release pipeline builds both platforms, verifies installer checksums,
checks the Mac bundle and DMG, and launches the packaged Mac WebView and local
proxy with disposable validation data.

Atlas 6 accounts, settings, and usage history are preserved. Windows continues
to use `%USERPROFILE%\.copilot-bridge-atlas`; macOS uses
`~/.copilot-bridge-atlas`. Atlas does not change Codex configuration or
authentication files.
