# Copilot Bridge Atlas 6.0.11

Request details now show a **Client** column immediately after **Time**. Atlas
recognizes Codex Desktop, Codex CLI, and Codex VS Code from incoming request
headers. Other Codex identifiers appear as **Codex — unspecified**; unrecognized
callers and older history appear as **Unknown**.

Detection prefers a recognized `originator`, then the incoming `User-Agent`,
before Atlas replaces upstream fingerprints. Client identity follows pending,
successful, and failed requests. Detection source and an available matching
client version are stored locally. Labels are self-reported, not authenticated.

The column uses the existing visibility controls. This update preserves saved
column selections and adds Client once. Database upgrades and older backup
restores preserve history. Model selection, forwarding, and token accounting
are unchanged.

Downloads:

- Intel Mac, macOS 13 or newer: `Copilot-Bridge-Atlas-6.0.11-macOS-Intel.dmg`
- Windows x64: `Copilot-Bridge-Atlas-6.0.11-Windows-x64.msi`

Each installer includes a matching `.sha256` file.
