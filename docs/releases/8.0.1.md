# Copilot Bridge Atlas 8.0.1

## Unknown-client diagnostics

- Log incoming request headers when Atlas cannot identify the client, before gateway header rewriting on either proxy listener.
- Preserve client identity and version metadata, including `User-Agent`, `originator`, `x-stainless-*`, and duplicate headers. Credential-header values such as authorization, cookies, API keys, and tokens are redacted; ordinary client metadata is not masked based on words in its value.
- Write one JSON-escaped `unknown_client` entry per unrecognized request to the existing application log. Do not add request bodies or URL query strings to these entries.
- Keep automatic client detection, UI, API behavior, routing, and usage accounting unchanged.
