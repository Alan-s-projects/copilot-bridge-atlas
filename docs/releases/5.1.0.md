# Copilot Bridge Atlas 5.1.0

Failure diagnostics now describe where a request failed and the structure of
the error. Upstream non-2xx responses, streaming failure events, connection
and timeout failures, and local proxy or response-conversion failures record
their stage, HTTP status when available, Atlas ID, safe upstream IDs, model,
transport, elapsed time, byte counts, encoding, and truncation state.

JSON errors record validated codes, types, parameter paths, diagnostic counts
and limits, and the field paths and value types of unfamiliar structures. A
Grok prompt-limit message records its prompt count and limit without retaining
the surrounding text. Numeric values outside diagnostic count and limit fields
are not logged. Free-form error text remains out of the file log and Usage
history, so echoed prompts, tool output, and credentials are not recorded. The
client still receives the original error response.

There is no database migration. Existing accounts, pricing, model choices,
backups and history are preserved. Install
`Copilot-Bridge-Atlas-5.1.0-Windows-x64.msi` and use its `.sha256` file to
verify the download. The per-user Windows installer is unsigned and is not
installed automatically by publishing this release.
