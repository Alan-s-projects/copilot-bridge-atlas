# Copilot Bridge Atlas 5.1.1

Atlas now records the exact upstream response body for failed HTTP requests in
the `atlas_http` warning and the matching Usage history entry, alongside the
structured diagnostics introduced in 5.1.0. Text is quoted to keep log entries
on one line. Unknown binary or compressed bytes are stored as Base64. Capture
is capped at 32 KiB and the warning marks larger responses as truncated.
Successful responses and the response delivered to the client are unchanged.

**Error bodies may echo prompts, tool output, or credentials.** Treat Atlas
logs and exported Usage history as sensitive while using this diagnostic
release. An upstream response containing only `Bad Request` cannot reveal a
more detailed rejection reason, even with exact logging.

There is no database migration or UI change. Install
`Copilot-Bridge-Atlas-5.1.1-Windows-x64.msi`; its `.sha256` file verifies the
download. The per-user Windows installer is unsigned and is not installed
automatically by publishing this release.
