# Copilot Bridge Atlas 6.0.5

Start-menu and desktop shortcuts now use the installed application's embedded
icon. Pins created from these shortcuts no longer depend on an MSI icon cache
that is removed when upgrading, preventing blank taskbar icons after updates.

The build checks the packaged shortcut targets, icon sources, and application
IDs before publishing the installer.

If a taskbar pin created by an older installer is already blank, unpin Atlas and
pin it again from the updated Start-menu shortcut once. The installer does not
change existing taskbar pins.

Install `Copilot-Bridge-Atlas-6.0.5-Windows-x64.msi` and verify it with the
matching `.sha256` file. Existing Atlas 6 accounts, settings, and usage history
are preserved.
