# Copilot Bridge Atlas 6.0.6

New releases are easier to notice: a compact **1** badge appears beside
**Settings** in the main navigation and **About** in the Settings sidebar.

Atlas checks for a newer stable release when the application opens. The two
badges share the result with the existing About release banner. Opening About
or viewing the release does not dismiss the notice. Once the installed version
is current, the badges and banner are absent.

The selected Settings badge uses a white background; other badges use a subtle
green background. The release banner and download link retain their existing
appearance and behavior.

Install `Copilot-Bridge-Atlas-6.0.6-Windows-x64.msi` and verify it with the
matching `.sha256` file. Existing Atlas 6 accounts, settings, and usage history
are preserved.
