# Copilot Bridge Atlas 6.0.1

This is an in-place update for Atlas 6. The application identity, data directory,
database format, window layout, and controls stay the same. Existing accounts,
settings, model selections, pricing overrides, usage history, and backups are
preserved.

- Copilot credentials use the shared atomic file writer. A failed replacement
  keeps the previous credentials file and cleans up its temporary file.
- Device sign-in polls wait for each request to finish. Logging out or removing
  an account cancels a pending sign-in flow, and successful account changes avoid
  duplicate status requests.
- HTTP client failures and malformed saved provider JSON are reported instead
  of being hidden by default values. Proxy loop detection covers IPv6 and bare
  host/port addresses; malformed proxy URLs no longer expose credential prefixes.
- Removed obsolete frontend token-count fallbacks, a retired configuration-error
  event listener, its unused process plugin and permission, and unnecessary
  rebuilding of the fixed tray menu after settings changes.
- Native Responses and Chat Completions share usage recording. Removed unused
  pricing arguments, redundant model-capability wrappers, and stale test mocks.
  Existing protocol adapters and conversation-ID repairs remain supported.
- The Windows pipeline also checks the catalog validation scripts.

Install `Copilot-Bridge-Atlas-6.0.1-Windows-x64.msi` and verify it with the matching
`.sha256` file. This update does not require deleting previous Atlas 6 data.
