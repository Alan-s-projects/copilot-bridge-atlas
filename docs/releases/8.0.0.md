# Copilot Bridge Atlas 8.0.0

## Internal quality and performance

- Replace repeated SSE buffer scans and copies with a shared incremental buffer across streaming adapters.
- Coalesce overlapping usage refreshes without discarding in-flight results or missing the final update.
- Move usage queries, pricing operations, and usage/diagnostic persistence off the UI and async streaming threads using existing blocking-worker facilities.
- Unify duplicated usage-completion paths and remove unused parser metadata.
- Avoid cloning diagnostic bodies for completion summaries and reuse runtime timers for usage notifications.

The UI and API contracts remain unchanged. This release does not add features, alter model routing, or change pricing and token accounting.
