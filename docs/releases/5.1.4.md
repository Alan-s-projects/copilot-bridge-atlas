# Copilot Bridge Atlas 5.1.4

Atlas now forwards the upstream `x-reasoning-included` response header unchanged
on Copilot Responses streams. It no longer adds the header when it is absent
for GPT-6 Astra or Luna. This matches betaHi/copilot-bridge's native Responses
header behavior. Reported token usage and encrypted reasoning items remain
unchanged, and there is no UI change.

This header change does not fix Codex's premature pre-turn compaction. An
isolated Luna test reproduced that behavior both with and without the header;
the upstream Codex accounting issue is tracked in
[Atlas issue #16](https://github.com/Alan-s-projects/copilot-bridge-atlas/issues/16).

Install `Copilot-Bridge-Atlas-5.1.4-Windows-x64.msi` and verify it with the
matching `.sha256` file. Publishing this unsigned per-user installer does not
install it automatically.
