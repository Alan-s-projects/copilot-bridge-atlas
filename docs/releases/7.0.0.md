# Copilot Bridge Atlas 7.0.0

Atlas now serves Claude clients through a separate Anthropic Messages API
listener while keeping the existing Codex connection intact.

- **Responses API:** `http://127.0.0.1:15722/v1` for Codex.
- **Messages API:** `http://127.0.0.1:15723` for Claude Desktop and Claude Code.
- One global proxy switch controls both listeners; ports and addresses are
  editable while stopped.
- Routing includes Claude role-to-Copilot-model mappings. Display names follow
  the target model automatically; no custom display-name inputs are needed.
- Connect provides Claude gateway settings and a Claude Code launch command.
- Recovered protocol converters support JSON/streaming messages, images,
  client-side tool calls/results, usage, and error translation through the
  existing Copilot account and transport pipeline.

Data and existing Codex settings are preserved. Claude token counting is an
explicitly marked estimate; server-side Anthropic features are limited by the
chosen upstream. Local API keys are placeholders, so use loopback by default.
See [gateway setup and limitations](https://github.com/Alan-s-projects/copilot-bridge-atlas/blob/atlas/docs/claude-gateway.md).

Downloads:

- Intel Mac, macOS 13 or newer: `Copilot-Bridge-Atlas-7.0.0-macOS-Intel.dmg`
- Windows x64: `Copilot-Bridge-Atlas-7.0.0-Windows-x64.msi`
