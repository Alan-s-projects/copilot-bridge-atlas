# Copilot Bridge Atlas 8.0.2

## Function tool compatibility

- Default function tools converted from Anthropic requests to the Responses API to `strict: false` when no valid boolean value is provided.
- Preserve explicitly supplied `strict: true` and `strict: false` values without changing tool schemas.
- Apply the same behavior to Copilot and Codex OAuth requests while leaving built-in web search tools unchanged.

## Downloads

- Windows x64 MSI
- macOS Intel DMG (macOS 13 or newer; ad-hoc signed, not notarized)

SHA-256 files accompany both installers.
