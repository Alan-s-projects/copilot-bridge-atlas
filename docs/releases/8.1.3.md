# Copilot Bridge Atlas 8.1.3

Atlas now estimates Copilot costs for GPT-6.2 Astra and GPT-6.2 Sol using
[GitHub's published rates](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing).
All rates are USD per million tokens.

| Model | Total input per request | Fresh input | Cached input | Cache write | Output |
| --- | --- | ---: | ---: | ---: | ---: |
| GPT-6.2 Astra | Up to 272,000 tokens | $8.00 | $0.40 | $10.00 | $40.00 |
| GPT-6.2 Astra | Above 272,000 tokens | $16.00 | $0.80 | $20.00 | $60.00 |
| GPT-6.2 Sol | Up to 272,000 tokens | $2.00 | $0.10 | $2.50 | $10.00 |
| GPT-6.2 Sol | Above 272,000 tokens | $4.00 | $0.20 | $5.00 | $15.00 |

Atlas fills in missing costs for retained requests when it seeds these prices.
Local overrides, deletions, and costs already recorded are preserved.

The generated Codex catalog now uses each model's own complete instruction
profile. The bundled snapshot is refreshed to OpenAI Codex `rust-v0.169.1`,
commit `c376cf7396eff83ce4c6ac61b9553df142e7a0be`, as part of the review tracked
in [issue #47](https://github.com/Alan-s-projects/copilot-bridge-atlas/issues/47).
Local synthetic captures verified prompt delivery in fresh chats and when
switching models with Codex CLI 0.169.1.
