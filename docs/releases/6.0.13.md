# Copilot Bridge Atlas 6.0.13

Removed redundant subtitles and descriptive hints from Overview, Usage, and
Settings, including the recent-request count/update hint, Rates range hint,
theme and startup descriptions, account-management description, backup
subtitle, and About description.

Headings, controls, automatic refresh, request limits, chart axes, and the
recent-requests table's screen-reader caption retain their behavior.

Downloads:

- Intel Mac, macOS 13 or newer: `Copilot-Bridge-Atlas-6.0.13-macOS-Intel.dmg`
- Windows x64: `Copilot-Bridge-Atlas-6.0.13-Windows-x64.msi`

Each installer includes a matching `.sha256` file.
