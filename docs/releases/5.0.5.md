# Copilot Bridge Atlas 5.0.5

Backup & Restore and Application Diagnostic Logs now appear below the existing
application information in **Settings → About**. The **Advanced** sidebar tab
has been removed. The two panel icons now use a neutral color. Both panels
retain their existing controls, layout, and behavior.

Opening About checks GitHub's latest published release. When its version is
newer than the installed app, a green reminder appears above the About card
with a link to that release. The check respects the configured outbound proxy;
if the check is unavailable, About remains usable without a reminder.
The About card keeps its GitHub link and no longer shows separate Release notes
or Download MSI buttons.

Install `Copilot-Bridge-Atlas-5.0.5-Windows-x64.msi`. The matching `.sha256`
file is provided to verify the download. The per-user installer is unsigned.

There is no database migration or settings reset. Existing backups, log
preferences, and application data are preserved. Publishing this release does
not install it automatically.
