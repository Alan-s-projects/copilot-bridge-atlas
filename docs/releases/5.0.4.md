# Copilot Bridge Atlas 5.0.4

This maintenance release removes unused backend code from the current delivery.

## Changes Since 5.0.3

- Removes the unused provider-statistics command and its query.
- Removes the unused cost-multiplier and pricing-source commands.
- Records new usage with the response model and a cost multiplier of 1.
- Preserves existing database columns, historical costs, and recorded metadata.

The visible UI, labels, layout, and settings behavior are unchanged.

## Installation

Install `Copilot-Bridge-Atlas-5.0.4-Windows-x64.msi`. A matching `.sha256` file
is provided for download verification. The per-user Windows installer is unsigned.

There is no database migration or settings reset. Publishing this release does
not install it automatically.
