# Copilot Bridge Atlas 7.1.2

## Claude Messages image-history safeguard

- Enable a backend-only 50-image safety budget for Claude Messages requests by default, including existing installations. No UI controls or layout changes are included.
- When over budget, replace only enough of the oldest eligible tool-result images with explicit omission markers. Preserve all user attachments, the latest tool-result batch, surrounding text, and tool-call/result identities. Requests within budget keep their images unchanged.
- Count normalized image occurrences, including supported tool-media wrappers, rather than unique URLs or generic message items. Original files and client transcripts are never edited.
- Reject requests locally with actionable guidance when protected images alone exceed the budget. Preserve upstream image-limit errors and add recovery advice without retrying after dropping images.
- Apply the same selection to the local token-count estimate and record image counts without adding image payloads to diagnostics.
- Support backend configuration for disabling the safeguard or overriding the budget by actual Copilot model ID. The default 50 is a conservative gateway budget, not a universal upstream model limit.

## Scope and limitations

- Direct Codex Responses requests, shared model routing, account selection, and the UI are unchanged.
- An omitted image is no longer visible to the model on that request; its marker is not a visual summary. Supply an older screenshot again when its details are needed. Changing earlier image content can reduce prompt-cache reuse.
- Protected attachments, lower upstream limits, document-derived images, and the separate Messages request-size limit can still require a smaller request or a fresh conversation. This is not a guarantee against every image-related error.
- Token counts remain estimates; usage records still use the upstream usage response. There is no database migration or client-configuration rewrite.
