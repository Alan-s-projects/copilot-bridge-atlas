# Copilot Bridge Atlas

A Desktop app connecting Codex/Claude → GitHub Copilot.

## Install and connect

1. Open **Settings → Accounts** to sign in to GitHub.
2. Then **Settings → Models** to refresh your models.
3. In **Settings → Models**, explicitly map Sonnet, Opus, Haiku, and Fable above **Enabled models**.
4. Turn on the proxy switch (right top).
5. Open **Connect**, review the guidance, and apply it yourself.
6. Reload Codex/Claude so it loads the selected settings.
