# Copilot Bridge Atlas 5.1.2

This release reverts 5.1.1's exact upstream error-body logging. Upstream
responses may echo prompts, tool output, or credentials, so Atlas once again
records only the structured diagnostics introduced in 5.1.0. A plain-text
upstream error records its type and byte count; the client still receives the
original response.

Logs and Usage history written by 5.1.1 are not rewritten by this update. Treat
existing 5.1.1 diagnostic records as sensitive. This release does not change
the underlying Grok HTTP 400 or its plain-text `Bad Request` response.

There is no database migration or UI change. Install
`Copilot-Bridge-Atlas-5.1.2-Windows-x64.msi` and use its `.sha256` file to
verify the download. The per-user Windows installer is unsigned and is not
installed automatically by publishing this release.
