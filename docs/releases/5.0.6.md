# Copilot Bridge Atlas 5.0.6

This release fixes Grok tool calls that serialize whole-number integer
arguments as decimals. When a Grok response contains a value such as
`session_id: 4876.0` or `yield_time_ms: 120000.0`, Atlas uses the original
tool schema to deliver `4876` or `120000` to Codex where an integer is
required.

The repair is always enabled for the resolved Grok model. It covers both
Copilot Responses and Chat Completions, including streamed tool calls and
namespaced tools. Atlas waits for affected streamed arguments to be complete
before publishing matching argument and completed-item events. Fractions,
strings, general numeric fields, and values without a clear integer schema
remain unchanged. GPT and Gemini follow their existing paths.

The UI and user settings are unchanged. There is no database migration or
settings reset. Existing accounts, model choices, pricing, and request history
are preserved.

Install `Copilot-Bridge-Atlas-5.0.6-Windows-x64.msi`. The accompanying
`.sha256` file verifies the installer. The per-user Windows installer is
unsigned. Publishing this release does not install it automatically.
