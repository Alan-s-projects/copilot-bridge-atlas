# Copilot Bridge Atlas 5.0.2

This release simplifies Settings navigation.

## Changes Since 5.0.1

- Renames the **Auth** sidebar tab to **Copilot**, where GitHub Copilot accounts
  are managed.
- Renames the former **Copilot** sidebar tab to **Models**, where the model
  catalog and reasoning options are configured.
- Removes the redundant **Manage accounts** button from Models and its duplicate
  account panel. Account selection remains available in Models.
- Updates the connection instructions in the README.

## Installation

Install `Copilot-Bridge-Atlas-5.0.2-Windows-x64.msi`. The matching `.sha256` file
is provided for download verification. The per-user Windows installer is unsigned.

There is no new database migration in this release. Accounts, preferences,
model choices, pricing, and request history are preserved. Publishing the release
does not install it automatically.
