# Copilot Bridge Atlas 5.0.0

5.0.0 marks the completed Atlas UI milestone, built from the remote `atlas`
head at 4.2.15. It brings the recent dashboard and Codex integration improvements
together under a new major version.

## Changes Since 4.2.15

- Updates the application and Windows installer version to 5.0.0.
- Keeps the same application behavior and UI as 4.2.15. This milestone does not
  introduce another redesign or new breaking changes.

## Included Milestone Features

These features were delivered across the recent 4.2.x releases and are included
in 5.0.0:

- Compact Overview with shared usage summaries, proxy status, active requests,
  and the latest five requests.
- Usage Trends with cost bars, cache-hit and success-rate lines, and stacked
  token bars. Click legends to hide or show series.
- Shared interval grouping from minutes to calendar months, with saved grouping
  and date-range preferences.
- Request logs and model statistics with configurable columns, cache metrics,
  reasoning details, pricing tiers, and costs.
- A streamlined Request Logs tab using the Usage header's date and model
  filters, without the extra inline filter toolbar.
- Copilot-provided model capabilities and context limits, model switching
  support, and the pinned upstream OpenAI Codex instruction data.

## Installation

Install `Copilot-Bridge-Atlas-5.0.0-Windows-x64.msi`. A matching `.sha256` file is
provided to verify the download.

This release adds no database migration or configuration reset. Existing
accounts, settings, custom prices, and request history are retained. Publishing
the release does not install the update automatically.
