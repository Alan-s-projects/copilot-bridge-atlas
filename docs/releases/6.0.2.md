# Copilot Bridge Atlas 6.0.2

This is an in-place Atlas 6 update. Existing accounts, settings, model selections,
pricing overrides, usage history, and backups are preserved.

- Chat Completions conversion keeps later instructions at their original
  conversation positions, preserving the earlier request context and tool
  history.
- Chat and function-only Responses adapters report unsupported opaque compaction
  items and history references instead of silently discarding them. Ordinary
  text summaries remain supported.
- Settings model rows show plain **Responses** or **Chat Completions** text before
  the reasoning levels. The vendor/image/parallel-tools display line is removed.
  Protocol text follows Copilot's advertised endpoints and the router's
  Responses-first preference.
- Overview's request table replaces Pricing Tier with **Input
  (fresh/cached/hit)** and places Duration immediately after Input.
- Cache-hit percentages are red below 50%, orange from 50% to below 80%, and
  green from 80% upward. Unknown rates remain neutral. Colors use the unrounded
  rate, including cache writes as misses.
- Usage's detailed request table keeps its existing columns, order, Pricing Tier,
  and column preferences. Its cache-hit percentages use the same new colors.

The generated model catalog's instruction templates and native Responses
forwarding remain unchanged.

Install `Copilot-Bridge-Atlas-6.0.2-Windows-x64.msi` and verify it with the matching
`.sha256` file. This update does not require deleting previous Atlas 6 data.
