# Copilot Bridge Atlas 5.0.3

This release clarifies the Settings sidebar labels and icons.

## Changes Since 5.0.2

- Renames **Copilot** to **Accounts** and uses the Lucide **Users** icon.
- Keeps **Models** and replaces its GitHub icon with Lucide **BrainCircuit**
  to represent AI models.
- Updates the README connection instructions.

The tab order, page contents, account management, and model behavior are unchanged.

## Installation

Install `Copilot-Bridge-Atlas-5.0.3-Windows-x64.msi`. A matching `.sha256` file
is provided for download verification. The per-user Windows installer is unsigned.

There is no database migration or settings reset. Publishing this release does
not install it automatically.
