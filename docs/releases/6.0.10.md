# Copilot Bridge Atlas 6.0.10

Selecting **Codex default list** in Connect now proposes a larger Codex context
budget together with removal of the custom catalog reference:

```toml
model_context_window = 872000
model_auto_compact_token_limit = 780000
```

Existing top-level values are replaced in the proposal. Matching values produce
no extra changes. Codex keeps its native model list and instructions; its client
and the upstream model still enforce their limits. These settings request a
larger local budget and do not establish successful near-limit Copilot serving.

The settings appear in the existing side-by-side Current TOML / Proposed TOML
comparison and are included when copying the proposal. Apply the TOML manually
after reviewing it. Atlas does not write your Codex configuration.

Atlas customized list remains the default and continues using catalog context
metadata. Catalog generation and refresh continue in both modes. The official
OpenAI sign-in proposal keeps its existing behavior.

- Windows x64: `Copilot-Bridge-Atlas-6.0.10-Windows-x64.msi`

Each installer includes a matching `.sha256` file.
