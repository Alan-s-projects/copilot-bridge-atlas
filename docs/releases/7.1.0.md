# Copilot Bridge Atlas 7.1.0

Claude Desktop connection checks and automatic title requests now identify as
**Claude Desktop** in Usage, alongside normal agent requests.

- Connect has a client sidebar for Codex, Claude Desktop and Claude Code. The
  Codex TOML path, connection/model-list selectors, diff and copy workflow remain.
- Settings → Models keeps GitHub account selection and Refresh models, places
  **Claude model mapping** above **Enabled models**, and removes the Ultra toggle.
- Ultra is always exposed for reasoning-capable enabled models. Atlas still
  translates unsupported Ultra requests to the model's highest supported effort.
- Each Claude role requires an explicit model. Numbered badges on Settings and
  Models show how many roles need attention and clear when the mappings are valid.
- Mapping and listener saves are ordered and merged to preserve independent edits.

**Upgrade:** existing explicit mappings are preserved. Roles that previously used
an automatic fallback must be configured in Settings → Models before use. Only
configured, enabled aliases appear in Claude model discovery. Unmapped or
unavailable roles fail clearly; Codex and other configured Claude roles continue.

Downloads:

- Intel Mac, macOS 13 or newer: `Copilot-Bridge-Atlas-7.1.0-macOS-Intel.dmg`
- Windows x64: `Copilot-Bridge-Atlas-7.1.0-Windows-x64.msi`

Each installer includes a matching `.sha256` file.
