# Copilot Bridge Atlas 4.2.12

This Windows x64 release includes all changes since **4.2.11**, including the
previously merged request-log and usage-dashboard improvements.

## More Reliable Model Switching

- Fixed malformed message IDs when continuing a Chat-backed conversation with a
  native Responses model.
- Fixed Gemini 3.8 Flash's rejection of complex Codex tool schemas. Atlas now
  uses a reversible JSON envelope and restores the original tool arguments.
- Fixed Grok 4.7's rejection of Codex namespace, custom, and tool-search tools.
  Atlas translates them to supported function calls and restores their identities.
- Verified tool calls against Copilot with Gemini and Grok in both streaming
  and non-streaming modes.
- Ultra reasoning maps to the highest effort reported by the selected model.
  It does **not** switch to a different model.

## Compact, Read-Only Model Catalog

- Model cards show the natural model name, input/total context limits, reasoning
  levels, and capabilities without editable metadata boxes.
- Names, limits, and reasoning levels follow Copilot's catalog. Refresh replaces
  old metadata overrides while preserving model enable/disable choices.
- Enable switches align at the far right, like the Ultra switch.
- **Saving / Saved** appears next to **Model catalog**, including during autosave.
- **Open generated JSON**, beside **Refresh models**, opens Atlas's generated
  Codex catalog in the default Windows app. It waits for pending saves to finish.

## Official Copilot Pricing and Long Context

- Replaced broad third-party defaults with the **33 model/mode entries** in
  [GitHub's Copilot pricing table](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing),
  checked September 27, 2026.
- Added all **11 published long-context tiers**, including their distinct input,
  cached-input, cache-write, and output prices. Fixed Grok 4.5's cached-input rate
  and added MAI-Code-1.1-Flash pricing.
- Tier selection uses total input tokens, including cached reads and cache
  writes. Output tokens do not affect the threshold. The higher rates apply to
  the entire request only when input is strictly above the published threshold.
- Both request tables now show **Pricing Tier**, immediately before **Cost**:
  **Default** or **Long context**. Unpriced/failed requests have no recorded tier.
- Add and Edit Pricing both support optional custom long-context pricing for
  any model, with an editable threshold and all four rates.
- The pricing table displays long-context rates beneath each model's default rates.

## Clearer Usage and Request Tables

- Request logs show **Reasoning (requested/applied)**, including fallback behavior.
- Renamed cache **Hit** to **Cached Input**, added **Cache Write**, and combined
  fresh input, cached input, and read-cache hit percentage into one input column.
- Corrected fresh-input display for cache writes and historical token semantics.
- Removed the ambiguous **Tokens Processed** summary.
- Aligned summary rows: Total Cost with token details, and Requests with Average
  Latency, Output Speed (TPS), and Success Rate.
- Overview retains a compact, efficiently refreshed five-request table. Usage
  keeps pagination and full token details. Both use the same table component.
- Timing columns display **Duration** only; TTFT remains available internally for
  output-speed calculations.
- Model Stats columns are now **Billing Model, Requests, Total Input
  (fresh/cached/hit), Total Output, Total Cache Write, Total Cost, Average Cost**.
  Token totals use compact notation with one decimal place.

## Upgrade Notes

- Upgrading migrates the database to schema 22; Atlas's normal pre-migration
  backup protects existing data.
- Unchanged old bundled prices are replaced by the official defaults. Explicit
  local overrides, deletion preferences, and edited/imported custom prices survive.
- **Previously recorded costs are not recalculated.** Older flat-rate request
  records remain marked Default even if their input would exceed a new threshold.
  Missing-cost backfills use the applicable tier; later price edits do not relabel
  already priced requests.
- Gemini 3.6/3.7/3.8 Flash's published promotional prices run through
  **December 31, 2026**. Pricing is a reviewed snapshot, not automatic web syncing.
- A different vendor cannot decrypt an opaque compacted history from another
  model. In that case, start a new chat or return to the previous model; Atlas
  reports the limitation instead of silently dropping that history.
- Estimated token costs are not a final subscription invoice or remaining
  Copilot allowance.

## Download

- `Copilot-Bridge-Atlas-4.2.12-Windows-x64.msi`: Windows x64 per-user installer.
- The accompanying `.sha256` file lets you verify the download.

Installing the MSI updates the existing Atlas installation and retains its
settings and data. Publishing this release does not install it automatically.
