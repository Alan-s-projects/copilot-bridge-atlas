# Copilot Bridge Atlas 6.0.8

The macOS menu bar now uses a centered, monochrome bridge symbol. The larger
bridge and transparent background replace the small full-color app icon, giving
Atlas a more consistent appearance beside the other menu bar icons.

macOS controls the icon's tint for light, dark, and selected menu bar appearances.
The bridge retains the existing arch and three supports.

This patch changes only the Mac menu bar icon. The Dock and application icons,
Windows tray icon, menu actions, accounts, settings, and usage history are unchanged.

Downloads:

- Intel Mac, macOS 13 or newer: `Copilot-Bridge-Atlas-6.0.8-macOS-Intel.dmg`
- Windows x64: `Copilot-Bridge-Atlas-6.0.8-Windows-x64.msi`

Each installer includes a matching `.sha256` file.
