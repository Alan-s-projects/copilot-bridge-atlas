# Copilot Bridge Atlas 7.1.3

## Usage filters and calendar ranges

- Add a Client filter alongside Model. Both filters apply together to Usage totals, trends, request logs, model statistics, and unpriced-usage warnings.
- Keep the toolbar compact and left-align Client and Model, with the date range on the right. Usage refreshes every 30 seconds; the interval selector is removed.
- Add **This week** (Monday through now) and **This month** (the first day through now), using local calendar boundaries that update on refresh.
- Retain per-client request, token, cost and timing metrics when new history is archived into daily rollups.
- Older aggregates without a reliable per-client breakdown are excluded from individual-client results with an explicit notice. **All clients** continues to include the complete original totals. Unknown callers remain distinct from history with unavailable breakdowns.

## Interface cleanup

- Remove the redundant Overview and Usage Statistics page titles; move Overview refresh beside Provider.
- Show a single shared Saved / Saving status for Claude model mappings, while retaining field warnings, errors and retries.
- Remove the redundant model-settings descriptions and the Models & account footer from Connect.
- Keep Connect as a top-level tab with its existing client sidebar. Accounts controls and authentication behavior are unchanged.

## Downloads

- Windows x64 MSI
- macOS Intel DMG (macOS 13 or newer; ad-hoc signed, not notarized)

SHA-256 files accompany both installers.
