# Copilot Bridge Atlas 5.0.1

This maintenance release cleans up retired code and fixes settings persistence
and request-log pagination. It preserves the 5.0.0 UI layout, labels, and styling.

## Fixes Since 5.0.0

- Orders chart-grouping and column-setting saves, including writes from separate
  consumers, so older saves cannot overwrite a newer selection.
- Shares one persistence implementation for date range, grouping, and columns.
  After queued saves finish, settings reconcile with the database; failed saves
  do not restore another failed optimistic selection.
- Allows malformed saved column preferences to recover to defaults and be
  replaced by the next selection, without changing unrelated settings.
- Resets request-log pagination when a custom range switches to a live end.
  When refreshed results shrink, the table returns to a valid page instead of
  remaining on an empty page beyond the result set.
- Stops startup before database migration if the required safety backup fails.
  The existing database remains available for recovery.

## Cleanup

- Removes the backend command, service, log writer, and scheduled cleanup for
  the already-removed health-check feature.
- Fresh databases no longer create the retired health-log table. Existing
  health-log tables and indexes remain untouched and are preserved in backups.
- Removes unused dialog/command-palette components and the unused `cmdk`
  dependency.
- Removes unused request-log filter props and stale tests for the removed
  toolbar; excludes generated Python bytecode from Git.
- Updates the README to describe the delivered UI and model metadata behavior.

## Upgrade Notes

- Install `Copilot-Bridge-Atlas-5.0.1-Windows-x64.msi`. The accompanying `.sha256`
  file verifies the download. The per-user Windows installer is unsigned.
- Database schema 23 records that health logs are no longer required. Supported
  older databases and SQL backups still upgrade, retaining accounts, settings,
  custom prices, request history, and opaque retired data.
- Earlier Atlas versions cannot open a schema-23 database. Keep the automatic
  pre-upgrade backup if you need to return to an older version.
- This release does not change model routing, context limits, instruction text,
  bundled prices, or historical request costs. No global Codex files are changed.
- Publishing this release does not install it automatically.
