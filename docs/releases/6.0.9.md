# Copilot Bridge Atlas 6.0.9

Connect now lets you choose the model list used in its proposed Codex
configuration:

- **Atlas customized list (Settings → Models)** is the default.
- **Codex default list** removes `model_catalog_json` from the suggestion.

The choice is remembered on this device. It affects the Connect suggestion
only: Atlas continues generating its catalog when models or settings change.
Apply the proposed TOML manually after reviewing it.

The existing side-by-side **Current TOML / Proposed TOML** comparison is
preserved. Its toolbar now shows a green check when no changes are needed or an
amber attention icon and line counts when changes are proposed. All three
configuration fields share the same input width.

This release also includes the reviewed Codex instruction refresh from PR #55.
GPT-6.1 Sol receives its own instruction profile instead of Astra's fallback.
The four bundled profiles are pinned to Codex `rust-v0.163.0`, source commit
`83086188ae0614bd882818ff1aa23f3194962012`. The maintenance script can compare
future upstream revisions without changing the saved snapshot.

Downloads:

- Intel Mac, macOS 13 or newer: `Copilot-Bridge-Atlas-6.0.9-macOS-Intel.dmg`
- Windows x64: `Copilot-Bridge-Atlas-6.0.9-Windows-x64.msi`

Each installer includes a matching `.sha256` file.
