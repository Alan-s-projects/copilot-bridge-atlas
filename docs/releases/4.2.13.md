# Copilot Bridge Atlas 4.2.13

This Windows x64 release includes the complete improvement batch since **4.2.12**.

## Clearer Overview

- A shorter Provider card replaces the long premium-request progress bar with a
  percentage ring, retaining the Copilot plan and reset date. The Health check
  action has been removed.
- **Today's usage** now uses the same two-row summary component as Usage, with its
  title inside the card. Both show Total Cost, Input (fresh/cached/hit), Output,
  Cache Write, Requests, Average Latency, Output Speed, and Success Rate.
- The refresh control is now an icon next to the Overview title, with a tooltip.
  The top-bar proxy control uses a server icon.
- Proxy status, address, and the active-request counter are together inside the
  Requests card. Status text uses the same muted monospace style as the address.
- The request table retains normal row heights and card borders, rather than
  stretching rows to fill the window.
- **Latest 5 requests** includes in-flight requests. Active rows show **Pending**
  and **N/A** for Duration, Pricing Tier, and Cost. Completed requests show their
  recorded values. Active requests do not inflate recorded usage or costs.
  Active requests appear first, followed by recent completed requests.
- Active rows update from lightweight in-memory status events; completion
  refreshes are coalesced, without adding an idle database-polling loop.

## Choose Your Columns

- A multi-select **Columns** dropdown controls the Usage request-log and Model
  Stats tables independently.
- All columns are visible by default. **Show all columns** restores that view,
  and at least one column remains selected.
- Choices auto-save as Atlas database settings and are included in database
  backups and SQL exports. Restoring a backup restores the saved choices.
- Missing or unavailable column settings fall back to all columns without an
  error banner. Failed saves retain the last saved selection.
- Overview keeps its own compact set of request columns.

## Fixed Settings Scrolling

- The app header, Settings heading, and section sidebar stay in place while only
  the right-hand content scrolls.
- Fixed invisible model-switch form inputs extending beyond the panel, which
  could scroll navigation offscreen and leave a clipped blank area at the bottom.
- Switching Settings sections resets the content scroll position.

## Smaller, Model-Neutral Codex Instructions

- Replaced the GPT-5.5-derived template and model-cache lookup with two maintained
  sources: a small Codex compatibility profile and one shared instruction file.
- The shared instructions are **564 words** and do not claim a particular
  underlying model. Both supported Codex instruction fields are generated from
  that single source.
- Model names, context limits, reasoning efforts, image input, and parallel-call
  capabilities continue to follow Copilot's declarations. Undeclared capabilities
  are not copied from another model.
- Validated catalog loading in the installed desktop and standalone Codex
  clients, plus live file editing, tool calls, streaming, and Astra/Luna/Sol
  switching within one session.
- Effective instruction text decreased from 19,754 to 3,960 characters. This is
  **not a token-cost saving claim**: tool schemas, conversation history, developer
  context, and caching also affect the request.
- No extra settings switch and no global Codex configuration changes.

## Recording and Pricing Checks

- Usage recording is always enabled. Removed the recording switch and duplicate
  request/connection/success counters from Proxy settings. Old disabled logging
  preferences no longer suppress new usage records.
- Added a fast pricing regression matrix across every bundled model, covering
  exact and exceeded long-context thresholds, cached input, cache writes,
  output-only requests, and zero/custom multipliers.
- Tests independently reconcile request line items with per-model totals and
  average cost, filtered and overall summaries, provider totals, and trends.
- Pricing rates and previously recorded costs are unchanged by this release.

## Upgrade and Download

- Install `Copilot-Bridge-Atlas-4.2.13-Windows-x64.msi`; the accompanying `.sha256`
  file verifies the download.
- Existing settings, accounts, and request history are retained. Active-request
  metadata is temporary and is removed when a request finishes or is cancelled.
- The generated model catalog updates when Atlas starts or its catalog refreshes.
  Codex loads the external catalog at startup; restart Codex to use the replacement
  instructions in new sessions.
- This release does not install itself automatically or rewrite Codex's global
  configuration. Existing opaque cross-vendor compacted-history limitations remain.
