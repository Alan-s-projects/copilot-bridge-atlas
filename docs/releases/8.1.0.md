# Copilot Bridge Atlas 8.1.0

## Native Copilot APIs

- Add native `POST /v1/chat/completions` (JSON and SSE) and `POST /v1/systemone` for Microsoft decision models. Unprefixed aliases are also available.
- Add native Responses WebSocket support on `GET /v1/responses` and the existing Responses aliases. Model eligibility is checked against the selected account's advertised transport for every response request.
- Keep Responses conversion, Messages, Compact, Search, and Images routes compatible with existing clients. The Messages listener remains separate.
- Resolve decision-model capabilities separately from chat-model selection, so hidden decision models do not become conversation model choices.
- Preserve native request data, including underscore-prefixed fields in SystemOne state and question names. Native upstream errors retain their status and body.

WebSocket connections pin one account, support sequential responses and cancellation, honor outbound proxy settings, and never automatically replay a request. They close on server shutdown, after an hour, or after five minutes without incoming traffic. Individual messages are limited to 16 MiB. Native clients must omit the browser `Origin` header; browser-origin calls to the new native APIs are rejected to prevent cross-site use of the signed-in account.

OpenAI `/v1/decisions` is not an alias for Microsoft SystemOne and is not exposed.

## Routing page

Keep the existing **Responses API** and **Messages API** sections. Each now has a collapsed **Exposed endpoints** list generated from the backend route registry: nine Responses-side entries and three Messages-side entries.

Each endpoint independently expands to a short description, sample input, and sample output. No search/filter toolbar or sample Copy buttons are added. Existing listener settings and base-URL copy controls are unchanged. Examples are illustrative; route availability does not guarantee model or account entitlement.

## Decision-model cost estimate

Add `microsoft-decision-1` using Microsoft's published Foundry reference price: **$0.042 per million input tokens; output tokens free**. Pricing settings identify the source and explicitly say that the actual Copilot price is unpublished.

The reference estimate counts all input tokens once, without inventing a cache discount. Existing model prices, custom overrides, deletion preferences, and recorded historical costs remain intact. Numeric edits are identified as user overrides rather than publisher-verified rates.
