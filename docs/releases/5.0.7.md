# Copilot Bridge Atlas 5.0.7

This maintenance release trims code left behind by earlier versions while
keeping the current UI and bridge behavior.

- Removes the retired daily-trend query used only by tests. The pricing and
  provider-filter checks now exercise the grouped trend query shipped in Atlas.
- Stops exposing the unused `showInTray` and `language` settings in the
  current app. Values saved by older versions remain opaque in `settings.json`
  and survive later settings edits. The interface continues to use English
  and closing the window continues to keep Atlas in the tray.
- Removes unused backend error cases, unused translation keys, redundant
  settings-panel props, and unused frontend exports.

There is no UI display change, database migration, settings reset, or change
to the proxy status API. Existing accounts, model choices, pricing, backups,
historical usage, and saved compatibility metadata remain intact.

Install `Copilot-Bridge-Atlas-5.0.7-Windows-x64.msi`. The accompanying
`.sha256` file verifies the installer. The per-user Windows installer is
unsigned. Publishing this release does not install it automatically.
