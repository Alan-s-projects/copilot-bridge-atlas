# Copilot Bridge Atlas 4.2.14

This release redesigns Usage Trends and replaces the custom instructions introduced
in **4.2.13** with unchanged instruction data from OpenAI's Codex source.

## Usage Trends and Saved Controls

- Splits trends into a cost bar chart, a 0-100% read-cache-hit/success-rate line
  chart, and stacked Fresh Input / Cached Input / Output / Cache Write bars.
- All charts use the existing Usage date range and model filters. There is no
  separate chart date selector or repeated date-range subtitle.
- Click a legend item to hide or show its series. Token axes use compact units
  with one decimal place; tooltips retain full counts and detailed costs.
- Adds shared grouping controls: **1, 3, 5, 7, 10, 15, 30, or 60** with
  **Minute, Hour, Day, Week, or Month**. The default is **1 Day**.
- Grouping and the selected date range auto-save in database settings and
  survive database backup/restore and SQL export/import. Presets remain rolling
  ranges; custom ranges retain their dates. Auto-refresh retains its existing
  app-settings persistence.
- Keeps the model filter, auto-refresh, and date selector beside the Usage title
  when space allows, reducing header height.
- Uses one aggregate query for all charts. Costs sum recorded values without
  repricing history; percentages derive from summed counts, not averaged rates.
- Empty intervals have zero costs/counts and unavailable rates have gaps.
  Daily-only archived data is explicitly flagged when finer or partial-day values
  cannot be reconstructed.
- Supports stable local-calendar boundaries, Monday-based weeks, real months,
  and daylight-saving transitions. Rolling 7/14/30-day ranges now count calendar
  dates rather than fixed 24-hour durations.
- More than 2,000 requested intervals produces an actionable error, without
  silently changing the saved selection.

## Exact Upstream Instructions

- Uses OpenAI Codex commit `d8ec479c34895214b44c062f060d97224c191a50`,
  specifically `codex-rs/models-manager/models.json`.
- GPT-6 Astra, Luna, and Sol receive their respective upstream instruction objects.
- Other model IDs, including Gemini and Grok, receive Astra's unchanged GPT-6
  instruction object. The GPT-6 identity wording is intentionally preserved.
  This does not change the actual model/provider used for a request.
- Copies the full `model_messages` object, including its additional instruction
  sections, rather than extracting or rewriting only the introductory text.
- The legacy `base_instructions` field mirrors the same upstream template.
  Literal examples, punctuation, null values, and trailing newlines are retained.
- Removes Atlas's authored 564-word prompt. There is no GPT-5.5 cache lookup,
  automatic prompt download, or new settings switch.

## Generation and Verification

- Copilot model IDs, context limits, reasoning levels, image input and parallel-call
  capabilities remain separate from the OpenAI instruction data.
- Adds a reproducible extraction/check script and SHA-256 fingerprints for the
  pinned source, each prompt, and each full instruction object.
- Rejects conflicting instruction overrides in the compatibility profile.
- Strengthens the installed-Codex checker to validate every request and model,
  including literal `{{...}}` examples that previously bypassed comparison.
- Verifies both fresh chats and model switching. Codex can retain the original
  base prompt while adding the new model's prompt as a developer message; the
  checker now validates that native behavior explicitly.
- Retains OpenAI's license and notices in the source and Windows installer.

## Upgrade Notes

- Install `Copilot-Bridge-Atlas-4.2.14-Windows-x64.msi`. The matching `.sha256`
  file is included for download verification.
- Start Atlas to regenerate its model catalog, then restart Codex and start a
  new chat to load the new base instructions. Existing chats may retain their
  original base prompt.
- Existing accounts, model enable/disable choices, settings, pricing, and request
  history are retained. No global Codex configuration is rewritten.
- These full OpenAI prompts are longer than the previous custom prompt.
  This release makes no claim of reduced input-token usage or cost.
- Publishing the release does not install it automatically.

## Grok Context Clarification

Copilot's live Grok 4.7 metadata, checked September 27, 2026, reports **500,000 total
context tokens**, **372,000 maximum prompt/input tokens**, and **128,000 maximum
output tokens**. Atlas retains those separate limits. With the configured 95%
effective-context budget, Codex CLI reports **353,400**, displayed as **353K**.
This was verified using Codex CLI v0.146.1; the input limit was not incorrectly
raised to the total-context limit.
