# Copilot Bridge Atlas 6.0.4

GPT-6.1 Sol usage now has a bundled price from GitHub's Copilot pricing table,
verified October 8, 2026. This removes the Unpriced model usage warning when
the bundled price is enabled and calculates costs for new requests.

Rates per one million tokens are $2 input, $10 output, $0.10 cached input,
and $2.50 cache writes. Requests above 272,000 total input tokens use the
published long-context rates: $4 input, $15 output, $0.20 cached input,
and $5 cache writes.

When the new price is loaded, Atlas also fills missing costs for retained
request logs, including the pricing tier for each request. Local pricing
overrides and deletions are applied first. Already recorded costs are
preserved; daily rollups whose individual requests were pruned cannot be
recalculated.

Install `Copilot-Bridge-Atlas-6.0.4-Windows-x64.msi` and verify it with the
matching `.sha256` file.
