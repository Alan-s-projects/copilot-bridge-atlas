# Copilot Bridge Atlas 6.0.12

The Cost chart now stacks costs by client, with consistent colors and a clickable
legend showing only clients present in the selected range. Hover shows client
costs and the combined interval total. Date grouping, provider/model filters,
and the overall cost total are preserved; token and rate charts are unchanged.

Client attribution now survives daily archiving. Older archives without client
information appear under **Unknown**, while existing labeled request history
uses its saved client. Incomplete archived time intervals remain gaps rather
than estimated values.

Atlas also recognizes **Claude Code** and **Claude Desktop** through known
entrypoints in their shared `claude-cli/` User-Agent family. Ambiguous headers
remain Unknown; recognized originators still take precedence. These rules come
from public upstream source and have not been validated with local Claude
traffic. Identification does not add Anthropic Messages API compatibility.
